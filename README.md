## 📋 Proje Hakkında

Bu proje, **MINAS Kafe**'nin kurumsal web sitesidir. Ziyaretçilere kafe hakkında bilgi sunmak, menüyü tanıtmak ve iletişim imkânı sağlamak amacıyla tasarlanmıştır.

### Özellikler

- 🌙 **Karanlık / Aydınlık Mod** — Kullanıcı tercihine göre tema değiştirme
- 🌍 **Türkçe / İngilizce Dil Desteği** — Çift dilli içerik
- 📱 **Tam Responsive Tasarım** — Mobil, tablet ve masaüstü uyumlu
- 📬 **İletişim Formu** — Formspree üzerinden doğrudan mail gönderimi
- 🖼️ **Galeri** — Kafe içi ve dışı görsellerle zengin sunum
- ⚡ **Hızlı ve Hafif** — Saf HTML, CSS ve Vanilla JS

---

## 🗂️ Proje Yapısı

```
minas-cafe/
├── index.html          # Ana sayfa
├── hata.html           # 404 hata sayfası
├── README.md           # Bu dosya
└── assets/
    ├── css/
    │   └── style.css   # Ana stil dosyası
    ├── js/
    │   ├── main.js     # Genel JavaScript
    │   ├── i18n.js     # Dil değiştirme
    │   └── theme.js    # Tema değiştirme
    └── images/         # Görsel dosyaları
```

## 🛠️ Kullanılan Teknolojiler

| Teknoloji | Açıklama |
|-----------|----------|
| HTML5 | Sayfa yapısı ve semantik işaretleme |

| Vanilla JS | Tema ve dil değiştirme, galeri modalı |
| Google Fonts | Outfit yazı tipi |
| Formspree | İletişim formu e-posta yönlendirmesi |
